AI examples and prompts

Analyze Cambridge crash trends

Start with the police crash dataset. Compare the Claude analysis with the shared ChatGPT conversation.

Claude Prompt (Fable 5.2 on the Claude website, slide 22)

https://data.cambridgema.gov/Public-Safety/Police-Department-Crash-Data-Updated/gb5w-yva3/about_data Please help me analyze this data set. I want to understand trends and any surprises. Please use charts and graphs to help me understand visually. And forcefully bring anything striking to my attention.

ChatGPT Prompt (Astra 6.2 on the ChatGPT website)

https://data.cambridgema.gov/Public-Safety/Police-Department-Crash-Data-Updated/gb5w-yva3/about_data Please help me understand this data set. Please use charts and graphs to help me understand visually. Please alert me to anything surprising or counterintuitive you find

Build a Cambridge 311 explorer

Open the Cambridge 311 Explorer in Claude. Select a request type or a time window to see how the map and charts change, or try the prompt with the 311 service requests dataset.

Claude Prompt (Fable 5.2 in Claude Code mode, desktop app)

Please create a Cambridge 311 data explorer as an artifact that I can share. It should have a variety of filter criteria that live update charts, a timeline and map that can plot individual complaints or region maps by density (by neighborhood, census tracts, etc). It should be powerful but intuitive and not overwhelming. You should be able to select a period of time on the timeline as a filter. You should be able to click play to animate the timeline so the data window moves automatically, updating the map and other charts.
https://data.cambridgema.gov/Public-Works/Commonwealth-Connect-Service-Requests/2z9k-mv9g/about_data

Research one building

Explore 47 Wendell Street · A House Atlas or open the single-address example in Claude.

ChatGPT Prompt (Astra 6 in Codex mode, desktop app)

Please create a chatgpt site for me that gives all the info about our house at 47 wendell street available from public sources (cambridge open data, historical commission DASH database, GIS, anything on the state level, permits pulled, realtor databases). If we have enough info for a 3d model, lets incorporate that too. It should have a nice visual component. If you need to download and install blender or something please do that too.

Claude Prompt (Fable 5.2 in Claude Code mode, desktop app)

Please create an artifact site for me that gives all the info about our house at 47 wendell street availalbe from public sources (cambridge open data, historical commission DASH database, GIS, anything on the state level, permits pulled, realtor databases). If we have enough info for a 3d model, lets incorporate that too. It should have a nice visual component. If you need to download and install blender or something please do that too. Please use the design skill to make it look good (not flashy and over the top, but with understated elegance and consistency with the theme). Please highlight any surprising findings and make it easy to go back to the original sources to verify.

Map buildings across Cambridge

Open the Cambridge Building Atlas to explore building outlines in 3D and see how construction years vary across the city.

ChatGPT Prompt (Astra 6 in Codex mode, desktop app)

Using cambridge open data and gis data, create a gpt site for me that shows a map of all buildings in the city and allows me to highlight buildings by various criteria, such as date of construction, dates of various permits, stylistic features, owner name, cost. It should be an elagant, intutitive but also powerful interface. The map should allow me to zoom and pan etc. I would love to see actual building outlines drawn on the map if possible.
Questions? Email opendata@cambridgema.gov.
